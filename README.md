# RiYueOauth 日月账号系统

一个给 Minecraft Java 服务器用的登录插件：注册账号、登录验证、邮箱找回密码、退出登录，
并把玩家的**背包、末影箱、统计信息**统一存到数据库，换服/换设备登录自动带回来。

---

## 先说清楚一件事：这是插件，不是数据包

原版数据包（function + 计分板那套）干不了这些事：

- 没法在玩家进服前拦住他、要求先登录；
- 没法安全地存密码和邮箱（数据 packs 里的东西玩家能改）；
- 没法把背包、末影箱、统计信息落库再还原。

所以按 **Spigot/Paper 插件**做，数据库用 **SQLite**（一个文件，不用另装 MySQL）。
适用于 Paper / Spigot 1.20.x ~ 1.21.x，需要 Java 17 或更高。

---

## 怎么用（小白版）

1. 拿到编译好的 `RiYueOauth.jar`（就在本项目 `target/RiYueOauth.jar`）。
2. 把它丢进服务器的 `plugins` 文件夹。
3. 重启服务器。第一次启动会自动生成 `plugins/RiYueOauth/config.yml` 和 `database.db`。
4. 进服，按提示注册登录。

### 命令

| 命令 | 干什么 | 例子 |
|---|---|---|
| `/zc 密码 [邮箱]` | 注册，注册完自动登录 | `/zc abc123456 game@mail.com` |
| `/l 密码` 或 `/login 密码` | 登录 | `/l abc123456` |
| `/pw 邮箱` | 获取找回密码验证码 | `/pw game@mail.com` |
| `/pw 验证码 新密码` | 用验证码重置密码 | `/pw 482913 newpass123` |
| `/zx` | 退出登录 | `/zx` |

密码默认 6~32 位，可在 `config.yml` 里改。

### 没登录时会怎样

不能走动、不能聊天、不能打命令（除了上面那几个）、不能拿东西、不能丢东西、
不能挖方块、无敌且打不了别人，背包里的东西会被先藏起来，登录成功后自动还回来。

管理员（OP）自带 `riyueoauth.bypass` 权限，不受限制。

## 找回密码怎么工作

两种模式，在 `config.yml` 里选：

**默认模式（不用配置）**：没配邮箱时，玩家执行 `/pw 邮箱` 后，验证码会打印在**服务器控制台**，
管理员看到后手动告诉玩家，玩家再执行 `/pw 验证码 新密码`。验证码 5 分钟有效。

**自动发邮件**：把 `recovery.smtp.enabled` 改成 `true`，填好邮箱服务器信息
（QQ 邮箱用 `smtp.qq.com`、端口 `465`、SSL 开，密码那一栏填**授权码**不是登录密码），
重启后验证码会直接发到玩家邮箱。

## 数据同步是怎么回事

数据存在数据库里，共三类：

- **账号**：玩家名、加盐哈希后的密码（不存明文）、邮箱、注册/登录时间；
- **背包和末影箱**：所有格子的物品，登录时自动还原；
- **统计信息**：走路、跑步、跳跃、死亡、击杀、挖掘、合成、钓鱼等。

**关于带特殊 NBT 的物品（如自定义装备、其他插件加的标签）**：完整支持。
物品是用 NBT 整组存取的，附魔、改名、Lore、CustomModelData，以及别的插件写进物品的私有标签
（比如 `{myplugin:{level:5}}`）都会原样存下来、登录时原样还原，不会变成普通物品。
NBT 库已经打包进插件并改过包名，你不用额外装任何东西，也不会和服务器上别的插件打架。
升级前的旧存档依然能正常读取，不受影响。

什么时候存：登录成功后、退出服务器时、执行 `/zx` 时、以及默认每 5 分钟自动存一次（可配）。

## 跨服同步背包（重点）

跨服的原理很简单：**所有服连同一个数据库**。玩家在 A 服下线时把背包写进库，
在 B 服上线时从库里读回来。账号密码也统一了，一处注册处处能登。

插件已支持两种模式，在 `config.yml` 里 `database.type` 选：

### 方案一：SQLite 共享文件（所有服在同一台机器）

1. 每个服的 `config.yml` 都填 `type: "sqlite"`，并把 `database.file` 指向**同一个路径**，比如
   `D:/mc-shared/riyue.db`（建议用绝对路径，别用默认的 plugins 相对路径，免得各服指向各自的文件夹）。
2. 所有服装同一个 `RiYueOauth.jar`。
3. 重启所有服。

适合小服、测试。缺点：多个服同时写数据库会抢锁，我已加了 10 秒等待和 WAL 模式缓解，
但并发大了还是可能卡顿。**正式跨服建议用方案二。**

### 方案二：MySQL（服在不同机器，或想要稳定）

1. 准备一个 MySQL 5.7+ 或 MariaDB 数据库，建一个空库：
   ```sql
   CREATE DATABASE riyueoauth DEFAULT CHARACTER SET utf8mb4;
   ```
2. 每个服的 `config.yml` 都填 `type: "mysql"`，`database.mysql` 下面填**同一个**地址、库名、账号密码：
   ```yaml
   database:
     type: "mysql"
     mysql:
       host: "你的数据库IP"
       port: 3306
       database: "riyueoauth"
       username: "账号"
       password: "密码"
   ```
3. 所有服装同一个 `RiYueOauth.jar`，重启。表会自动建好，不用手动建表。
4. MySQL 要允许远程连接（改 `bind-address`、给账号授权 `%`），如果是云服务器记得开 3306 安全组。

MySQL 驱动和它依赖的组件都已经打包并改过包名，不会和服务器自带的东西冲突。

### 已处理的坑

- **切服背包回退**：玩家从 A 服退出的瞬间就同步写库，写完才断线，
  B 服登录时读到的一定是最新背包（异步写会导致 B 服读到旧数据）。
- **断线重连**：MySQL 连接空闲被服务端掐断后会自动重连。
- **大小写**：用户名、邮箱查询不区分大小写，UTF-8 中文物品名正常。

### 测试方法

A 服注册登录 → 背包放一把带改名的钻石剑 → 退出 → 连到 B 服登录 → 看剑在不在、NBT 标签在不在。

> 注意：群组服要保证同一时刻玩家只在一个服在线。如果玩家同时在两个服都登录并改背包，
> 后保存的会覆盖先保存的——这是所有共享数据库方案的通病，用代理（BungeeCord/Velocity）强制单点登录可解。

## 常见问题

**Q：玩家进服后一直提示登录，但背包空空的？**
A：正常，未登录时背包被藏起来了。登录成功后会从数据库加载；老玩家数据库没记录的，会把进服时身上的东西还回去。

**Q：忘了密码又没填邮箱怎么办？**
A：让管理员用控制台改动数据库，或者管理员在服务器里让玩家用 `/pw 邮箱` 走控制台验证码流程（前提是注册时填了邮箱）。

**Q：会不会卡服？**
A：密码哈希和数据库读写都在异步线程做，主线程只负责改玩家背包这些数据，不会卡。

**Q：怎么跳过登录限制调试？**
A：给自己 OP 权限（`riyueoauth.bypass`），或者直接 `op 你的名字`。

## 自己编译（可选）

项目用 Maven。装好 JDK 17+ 和 Maven 后，在项目根目录执行：

```
mvn clean package
```

产物在 `target/RiYueOauth.jar`，已经把 SQLite 驱动打包进去了，服务器不用额外装东西。
